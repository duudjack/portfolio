# Mouhamet Diene — Developer Portfolio

Responsive static portfolio with four career-focus views and six project case studies.

## Files
- index.html: page structure and contact information
- styles.css: responsive theme, focus styles, reduced-motion and print rules
- script.js: project content, role filtering, and native case-study disclosures
- vercel.json: static hosting configuration and response headers
- .gitignore: excludes local environment and deployment files

## Preview
Keep the web files together. Open index.html or run `python -m http.server 8000` and visit localhost:8000.

## Career-specific links
Append ?focus=software, ?focus=data, ?focus=security, or ?focus=science to the site URL.

## Deployment
The source is configured for a static Vercel deployment with no install or build step and the repository root as output. A configuration file is not proof of a successful deployment.

## Editing and publication
Update project content in script.js and contact information in index.html. Confirm student status, email, LinkedIn address, contribution statements, and demo links before sharing. No private application source or placeholder resume is included. Planned work is labeled as planned.

## Verification scope
Descriptions reflect selected source files reviewed in November 2026 and prior project discussions. Applications were not executed, demo links were not retested, and The Grid archive was not unpacked. No formal accessibility or security audit is claimed.
