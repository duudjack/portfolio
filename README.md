# My Portfolio

This is my personal portfolio. It brings together some of the projects I've worked on, with links to the code and a little background on each one.

I wanted a place to show what I've been making, explain how things work, and keep track of what I want to improve. Some projects started as class assignments, while others came from things I was interested in trying out.

## What's on the site

- Projects with descriptions, the tools used, and links to the repositories or demos where available.
- A closer look at how each project works and what still needs work.
- A few ideas for projects I want to build next.
- A little about me and ways to get in touch.

The projects are at different stages. Anything that's still a prototype or just an idea is labeled that way.

## Built with

HTML, CSS, and JavaScript. No framework or build step is needed to run the portfolio itself.

## Running it locally

Download or clone the repository, keep the files together, and open `index.html` in your browser.

You can also run a local server from the project folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Where things are

- `index.html` has the main page content and contact links.
- `styles.css` handles the layout and styling.
- `script.js` has the project information and interactive parts.
- `vercel.json` contains the hosting settings for Vercel.

## Still working on

I'll keep updating this as I improve the projects and have more work to share. The next steps are adding better demos, testing more thoroughly, and going into more detail about how the projects were put together.
